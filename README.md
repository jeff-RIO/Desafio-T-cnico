# Desafio Técnico – Controle de Filiais e Estoque

Aplicativo mobile/web desenvolvido com **React Native + Expo** para centralizar o cadastro de lojas e produtos de uma rede de varejo, substituindo o controle manual feito em planilhas.

## Visão geral

O sistema permite:

- Listagem de lojas
- Cadastro de novas lojas
- Edição e exclusão de lojas
- Listagem de produtos por loja
- Cadastro de novos produtos
- Edição e exclusão de produtos
- Busca local de lojas
- Busca local de produtos

## Stack utilizada

- **Expo**
- **React Native**
- **TypeScript**
- **Expo Router**
- **Zustand**
- **MirageJS**
- **Gluestack UI**
- **StyleSheet** para estilização híbrida e compatibilidade web

## Requisitos

Antes de rodar o projeto, tenha instalado:

- Node.js
- npm
- Expo CLI via `npx expo`
- Navegador ou emulador Android/iOS
